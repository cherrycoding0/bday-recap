팬덤 데이터 분석에서 출발해 바이럴 루프를 설계하고, 이를 뒷받침하는 기능 9개를 구현·검증·배포했다.

## 1. 데이터 기반 기획

- 콘서트 예매자 통계(여성 94~98%, 10~20대 초반 약 80%)와 팬덤 활동 채널(트위터·위버스)을 분석해 설계 전제 수립:
  **① 모바일 온리 ② 위버스는 링크가 아닌 이미지로 확산 ③ 친목 문화 = "너는 뭐 나왔어?" 대화 유발이 핵심**
- 핵심 바이럴 루프 설계: `유형 테스트 → 결과 카드 → SNS 인증 → 친구 유입 → 메시지 작성(904 목표 기여)`
- 기능별 우선순위·일정을 기획서(`docs/feature-plan.md`)로 문서화 후 구현 착수

## 2. 구현 기능

### 오프 성격 유형 테스트 (바이럴 엔진)
- 5문항 × 2축(덕질 온도/스타일) 점수 → 6유형 분류
- **결과 분포 검증**: 전체 답 조합 243개를 시뮬레이션해 특정 유형 쏠림(32%/5%) 발견 →
  if-else 경계 대신 **대표점(prototype) 최근접 분류**로 교체, 유형별 12~19%로 균등화
- 유형당 곡 여러 개 등록 → 결과마다 랜덤 파트 + "다른 파트도 보기 🔀" (직전 파트 제외 리롤)
- 콘텐츠(문항·유형·가사·직캠)는 `config/quiz.ts` 단일 파일로 분리 — 비개발자도 수정 가능

### 완성 카드 (참여 보상)
- 메시지를 남겨야 닉네임 + 순번("#0001번째 원도어")이 새겨진 카드 발급 → 테스트 유입을 롤링페이퍼 참여로 전환
- **Canvas API로 1080×1350 카드 이미지 클라이언트 생성** (외부 이미지 없이 팔레트+타이포 — 저작권·CORS 안전)
- 유형 테스트를 완료한 상태에서만 메시지 폼 오픈 (재시작하면 다시 닫힘)

### Supabase 백엔드 (총 3차 마이그레이션)
- v1: messages 테이블 + RLS(익명 읽기/쓰기)
- v1.5: `seq`(identity 순번), `hearts` 컬럼, `heart_message()` **security definer RPC** — 익명 사용자가 하트 +1만 가능, content 수정 불가
- v1.6: `admins` 테이블 + **관리자 삭제 RLS 정책** — 프런트 숨김이 아니라 DB 레벨 권한. 무단 REST 호출도 서버가 거부
- 메시지 10자 미만 차단을 클라이언트 + **DB CHECK 제약(NOT VALID)** 이중으로

### 콘텐츠 필터 (3중 방어)
- 1차: 비속어(공백/특수문자 우회 정규화)·링크(dot 우회 포함)·연락처 유도·도배·영타 우회(tlqkf 등) 차단
- 부분 문자열 매칭 특성상 오탐 위험 단어("자지"→"일찍 자지 마" 등)는 의도적으로 제외하고 사유 주석화
- 오탐 6종 / 차단 10종 유닛 테스트 작성·통과

### AI 기능 + 비용 방어
- `/api/recap`: 전체 메시지 → AI 요약 카드. **1시간 인메모리 캐시 + IP 레이트리밋** — 방문자가 아무리 눌러도 AI 호출 시간당 최대 1회
- `/api/comment`: 카드용 개인화 한 줄 생성. 키 없음/실패/리밋 초과 시 **유형별 템플릿 폴백** — 카드 발급은 절대 안 막힘

### 운영 도구
- 관리자 로그인(Supabase Auth) → 메시지 2-탭 삭제
- `/photo-picker`: 사진 212장을 클릭으로 골라내고 **완성된 설정 코드를 클립보드로** 복사하는 큐레이션 페이지

### UI/연출
- 성호 최애 색 '라이트 퍼플' 기반 라벤더 팔레트 + Neo둥근모 폰트 (셀프호스팅, 빌드 시 네트워크 무의존)
- 폴라로이드 포토 슬라이드(공식 트위터 212장 자동 수집, 3초 랜덤 전환, 탭하면 다음 사진)
- 메시지 띠배너(랜덤 12개 무한 루프) · 904 목표 진행바 · D-day 자정 폭죽 모드 · OG 이미지 제작

## 3. 트러블슈팅 기록

| 문제 | 원인 | 해결 |
|---|---|---|
| 유형 결과 쏠림 (프로형 32%, 눈물샘 4.9%) | 경계 규칙식 분류의 사각지대 | 243개 전 조합 시뮬레이션 → 대표점 최근접 분류로 균등화 |
| iOS(카톡/사파리/크롬)에서 띠배너 정지 | iOS 웹킷 CSS 키프레임 이슈 | requestAnimationFrame 구동으로 교체 (`translate3d`) |
| 모바일에서 폴라로이드 무반응 | 터치 기기엔 hover 없음 | 탭 → 다음 사진 전환 + `:active` 피드백으로 재설계 |
| "ㅇ" 한 글자 메시지 등록됨 | 길이 검증 부재 | 10자 규칙 + 자모 도배 차단 + DB CHECK 제약 |
| 카운트다운 hydration 경고 위험 | 서버/클라 시각 차 | 마운트 전 "--" 렌더로 해소 |
| 하트 무한 클릭 가능성 | 익명 update 권한 문제 | security definer RPC로 +1만 허용 |
| SVG 하트 프레임이 세로 사진을 크게 잘라냄 | 3:4 사진 vs 하트 형상 | 폴라로이드 프레임으로 전환 (사용자 피드백 반영) |
